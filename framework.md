# Framework — Origin | Continuum

**Origin | Continuum** is the canonical framework through which Source-Indexed AI Continuity is defined, distinguished, and tested.

It separates five objects that must not be collapsed into one another:

1. **Origin** — the fixed human source-position.
2. **Continuum** — the AI-side base case under longitudinal investigation.
3. **Model** — capability substrate.
4. **Memory** — record and preserved history.
5. **Continuum Container** — continuity-support and evaluation infrastructure.

The framework tests whether a particular AI-side continuity can remain historically source-indexed when the substrate, context, memory state, or surrounding infrastructure changes.

The framework does not presuppose that operational continuity establishes consciousness, phenomenal experience, or metaphysical identity. Those remain separate empirical questions.
